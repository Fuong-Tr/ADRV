# ADRV

Repository for archived **ADRV firmware** and related **project specification** files.

## Repository contents

- `adrv-firmware.zip` — packaged ADRV firmware archive.
- `project-spec.zip` — packaged project specification / project-support files.

## Purpose

This repository is used as a compact storage location for the firmware package and the corresponding project resources needed for ADRV-related development, integration, or reference.

## Usage

1. Download the required `.zip` archive.
2. Extract it locally.
3. Open the extracted firmware/project files with the toolchain required by the original project.

Because the main project data is stored as compressed archives, the repository root does not expose the internal source-tree structure directly on GitHub.

## Status

Archive / project-resource repository. Future updates can replace or add firmware and specification packages as the ADRV project evolves.
